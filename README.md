# 🔄 JavaScript Unit Converter

A **fully functional unit converter** built using **HTML, CSS, and JavaScript** with a clean, user-friendly interface and essential conversion features, designed for converting different units of measurement quickly and easily.

---

## Features

### Basic Controls
- `Input` – allows users to enter a numerical value.
- `Category Selection` – lets users choose a measurement category.
- `Convert` – converts the entered value into the selected unit.
- `Swap` – switches the selected source and target units.

### Unit Conversion
- Supports multiple measurement categories, such as length, weight, temperature, and volume.
- Provides different units for each measurement category.
- Displays the converted result instantly.
- Automatically updates available units based on the selected category.

### Additional Features
- Validates input to prevent invalid conversions.
- Handles decimal values for more accurate results.
- Allows users to convert between different units easily.
- Displays conversion results in a clear and organized format.

---

## How It Works

The unit converter uses **JavaScript calculations and DOM manipulation** to process user input, identify the selected measurement units, and display the converted values dynamically without reloading the page.

**Example Usage:**
1. Enter a numerical value in the input field.
2. Select a measurement category.
3. Choose the unit you want to convert from.
4. Select the target unit.
5. Press `Convert` to display the converted result.
6. Use `Swap` to reverse the selected units.

---

## Technologies Used
- **HTML** – structures the unit converter interface.
- **CSS** – styles the layout and design.
- **JavaScript** – handles conversion calculations and user interactions.
